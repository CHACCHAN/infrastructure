# tests

管理 API の差分計算と、実際の Ansible タスクの安全性を、架空の値とローカルの模擬 API で検証する。実環境の接続情報・Vault・SSH は使わない。

Ansible と PyYAML が導入された Python 環境、およびテスト用の一時証明書を作る OpenSSL が必要。追加のテストサービスは不要。

```sh
python -m unittest discover -s tests -p 'test_*.py' -v
```

API の部分更新、未指定の真偽値・認証情報・認可情報の保持、表示に秘密値が混ざらないこと、冪等性を検証する。実環境での設定更新をテストの代わりに実行しない。

模擬 API の試験では `127.0.0.1` だけで HTTPS を受け、架空のトークンと一時的な Vault パスワードを使う。発行・ローテーションの応答失敗後の回復、停止と通常適用の分離、別キーの保持、排他ロック、確認値、取得記録による台帳上書きの拒否、ページングと部分更新を、実際の Ansible タスクで検証する。
